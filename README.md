# 夜曲 Nocturne

[開啟 Virtual Piano（GitHub Pages）](https://onelif2.github.io/virtual-piano/)

不用安裝。如收到 ZIP，先完整解壓縮並保留資料夾結構，再以瀏覽器開啟 `index.html` 即可。不載入外部資源，不需登入，不使用咪高峰。

## 演奏畫面

揀樂曲同模式，再按 **開始**。琴鍵固定喺下方，25／61／88 鍵可隨時切換。

- **桌面**：橫譜由右向左移，中間偏左嘅直線標示而家要彈嘅位置。上方可切 **QWERTY**（實體鍵盤鍵位）或 **CDE**（音名），毋須停歌；冇對應電腦鍵嘅音會顯示音名，可用滑鼠彈。超闊螢幕開頁預設 61 鍵。
- **手機或較窄嘅視窗**：保留直向落音，提示同琴鍵左右對齊。可直用或橫放，用「低音／高音」移動較闊嘅鍵盤。

平時只需用樂曲、模式同播放控制。要改音色、音量、節拍器，或者用四軌錄音、MP3 匯出同音符便箋，打開右上角 **工具**。收起工具唔會刪除錄音。

## 三種模式

- **Demo 示範**：自動彈旋律；跟住提示同高亮琴鍵睇，可以暫停或拖時間軸重聽一句。
- **Play Along 跟彈**：低音伴奏照拍前進，主旋律由你彈。當組嘅每個音只計一次；錯過唔會令首歌停低。
- **Practice 練習**：等你彈啱先前進。和弦可逐個音彈，已彈啱嘅音會淡出提示，剩低嘅繼續亮住；彈錯唔會倒退。

同一首歌中途切換模式，會留喺目前位置；原本暫停就繼續暫停。只有「重來」或換歌先由開頭開始。轉入 Play Along 會由目前位置重新計分。開始跟譜時，實體鍵盤會重設為 C3–C5 同原調，並保留所選嘅琴鍵顯示。Demo 同 Play Along 沿用開始嗰刻嘅 BPM。樂曲為原創練習曲及三首公有領域曲調的簡易編排，不含參考網站的程式、資產或樂譜。

在樂曲選單揀 **Canon in D（D 大調卡農）**，再按 **Practice 練習 → 開始**。呢個 18 小節初階編排由單音開始，再加入四分音符同結尾和弦。

## 自由演奏

- 可用滑鼠、觸控、多指或實體鍵盤。常用白鍵為 **Z X C V B N M** 和 **Q W E R T Y U I**，黑鍵會在琴鍵上顯示。
- **琴鍵顯示**可選 25 鍵、五個八度（61 鍵）或 88 鍵（原調 A0–C8）。五個八度會跟隨實體鍵盤音域，較窄畫面可用「低音／高音」移動琴鍵。所有畫面都沿用相同嘅實體鍵盤配置。
- **Space** 在焦點不在互動元件上時是暫時延音；也可點延音鈕。可調音域、半音移調和音量。
- 節拍器支援 40–240 BPM 和 2、3、4、6 拍。四軌錄奏可依序覆錄、靜音及混音。錄奏保存在目前頁面，重新整理便會清除；可先匯出真正的 44.1 kHz、128 kbps 雙聲道 MP3。每軌錄製上限約三分鐘；匯出最多三分鐘及 6,000 個可聽音符。
- 音符便箋以空格分隔。例：`C4 E4 G4 | C4+E4+G4:2 R:0.5 Bb4`。音符範圍 A0–C8；不在鍵盤畫面內的音符仍可播放。
- 若聽不到聲音，點一下琴鍵讓瀏覽器啟用聲音。以 Tab 選擇琴鍵，Enter 或 Space 可彈奏。

## 編碼器與授權

提供 96 款瀏覽器即時合成音色。MP3 編碼使用 LAME via lamejs (LGPL)，詳見 [編碼器授權及原始碼來源](vendor/NOTICE.md)。

## GitHub Pages

把網站檔案（含 `index.html`、音色模組及編碼器）放在目標發布根目錄，用倉庫的 **Settings → Pages → Deploy from a branch** 選擇 `main` 分支及 `/ (root)` 目錄，再按 **Save**。若倉庫主分支不叫 `main`，選擇實際分支。不需要組建步驟。尚未發布時也可直接本機試用。

## 開發驗收

如要執行琴鍵視圖嘅 DOM 回歸測試，喺專案目錄用 Node.js 安裝測試依賴並執行：

```sh
npm install --no-save --no-package-lock jsdom
node --test tests/keyboard-range.cjs
node --test tests/song-modes.cjs
```

測試涵蓋鍵數、鍵位映射、視圖切換時嘅按鍵釋放、Canon in D 練習提示同便箋回放。開啟網頁演奏毋須安裝測試依賴。

另有 Python Playwright 瀏覽器測試：`tests/stage-browser.py` 接受本機 HTML 路徑或公開網址，驗證桌面橫譜、手機落音、琴鍵貼底同工具開合；`tests/smoke.py` 會實際錄音、匯出並用 FFmpeg 解碼 MP3。測試可用 `CHROMIUM_PATH` 指定已安裝嘅 Chrome。
