# Nocturne · Virtual Piano

[開啟 GitHub Pages](https://onelif2.github.io/virtual-piano/)

## 2026-11-23 首頁更新

- 預設 34 鍵 G2–E5；I＝中央 C、CL＝Caps Lock／A2；鍵位不隨提示方向改變。
- 預設音色 001 Concert Grand Piano；Sounds 有 95 個選項、93 組公開取樣音源，按需下載、驗證 SHA-256 並解碼。兩個鋼琴別名使用 FluidR3 公開鋼琴取代未核實授權的 OP 專有錄音。
- 琴鍵音名預設「不顯示」；保留 QWERTY 電腦快捷鍵、琴譜提示及無障礙音名。
- Demo、Play Along、Practice 共用 Canon 的 192 個音及原譜時序。開頭 4.8 秒是休止。
- 「提示」可選直向落鍵、橫向讀譜或自動；同時和弦上下行對齊。
- 「提示」選單固定在讀譜上方右側控制列；切換橫向、直向及自動模式不會跳到底部，手機及橫放亦保留相同位置。
- Practice 長音只需點按；距有效時段 ≤200ms PERFECT／1000、≤400ms GREAT／700、≤900ms GOOD／300、≤1300ms POOR／100；超時或下一組不同開始時間的音符到達即 MISS／0。和弦同組不會互相截止。PERFECT／GREAT／GOOD 都 Combo +1，POOR／MISS 歸零；血量分別 +2／+1／0／−5／−10。最高 1,000,000 分，屬本頁自訂規則，不是 Konami 官方數值。
- 錯鍵或 MISS 返回目標並等待按對；更正後從該音按原時值續播，不立即跳往下一音，補彈不抹走已有 MISS。和弦可分別點按。
- 時間條可返回重練；跳轉後停住，按任何可演奏電腦／畫面琴鍵開始，亦可按開始掣。放鍵後才載入完畢不會補播幽靈琴聲。
- Demo：背景音樂＋自動琴鍵／琴聲。
- Demo 自動示範仍為綠字。手動判定 PERFECT 橙、GREAT 紫、GOOD 藍，只有 POOR／MISS 紅；未判定中性色。琴鍵實際按下仍亮藍。
- Demo 和弦中每一個正在發聲的琴鍵都完整填色：旋律金色、另一聲部藍色；不再只用窄邊條表示另一聲部。
- Play Along：背景音樂＋手動琴鍵／琴聲；不會自動彈奏譜音。
- Play Along 琴鍵不顯示綠色目標框、綠點或命中條；只顯示真實手動按鍵的藍色亮鍵。上方琴譜提示仍保留，Practice 目標助手不受影響。
- Practice：Play Along＋彈錯／漏音返回目標並停等，按對才繼續；背景音樂同步停止及恢復。

此版沿用儲存庫既有 [Canon 背景音軌](scores/media/canon-practice.m4a)，檔案未變。背景、琴鍵及提示共用音訊時鐘。程式檔相對路徑同源載入，取樣來自固定 commit 的公開 MIDI.js Soundfonts 上游；僅讀取音訊資料，不執行下載的 JavaScript。首次載入需網絡，失敗會清楚標示合成備用及提供重試。來源、作者、CC BY／BY-SA 授權與鋼琴替代說明見 [SAMPLE-NOTICE.txt](SAMPLE-NOTICE.txt)。未公開本機 OP 專有 soundfont 或新增其單音錄音。

## 使用

開頁後按「開始／開始練習」啟用聲音；背景音軌首次載入完成後才會開始計時，開頭 4.8 秒休止屬正常。Practice 的譜會隨節奏前進，除非按錯／漏音而停等。工具內可分別調總音量（預設 100%）、背景音量（預設 50%）、琴鍵加強（自動及手動共用，預設 +5 dB＝增益約 178%）；Play Along／Practice 的手彈加強預設亦為 +5 dB，因此手彈合計 +10 dB＝增益約 316%。琴鍵專用增益不會放大背景音軌。以上百分比是數碼增益，不代表喇叭實際分貝或主觀響度；壓縮器仍保留防止大和弦削波。沒有咪高峰或登入要求。
