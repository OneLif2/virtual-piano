# 夜曲 Nocturne

不用安裝。如收到 ZIP，先完整解壓縮並保留資料夾結構，再以瀏覽器開啟 `index.html` 即可。不載入外部資源，不需登入，不使用咪高峰。

## 三種模式

- **Demo 示範**：自動播放作品並指出當前音符。
- **Play Along 跟彈**：時間持續前進，播放簡單的低音伴奏。跟著琴鍵標示彈主旋律，每個時間段內彈對的音符會計分。
- **Practice 練習**：不計時，只有彈對才進入下一組。遇到和弦可逐個按；彈錯不扣進度。

三種模式使用固定 C3–C5、原調配置，完成後可再次開始。除練習外，速度取自開始時的 BPM。停止前可隨時另選模式或樂曲。樂曲為原創練習曲及兩首公有領域曲調的簡易編排，不含來源網站的程式、資產或樂譜。

## 自由演奏

- 可用滑鼠、觸控、多指或實體鍵盤。常用白鍵為 **Z X C V B N M** 和 **Q W E R T Y U I**，黑鍵會在琴鍵上顯示。
- **Space** 在焦點不在互動元件上時是暫時延音；也可點延音鈕。可調音域、半音移調和音量。
- 節拍器支援 40–240 BPM 和 2、3、4、6 拍。四軌錄奏可依序覆錄、靜音及混音。錄奏保存在目前頁面，重新整理便會清除；可先匯出真正的 44.1 kHz、128 kbps 雙聲道 MP3。每軌錄製上限約三分鐘；匯出最多三分鐘及 6,000 個可聽音符。
- 音符便箋以空格分隔。例：`C4 E4 G4 | C4+E4+G4:2 R:0.5 Bb4`。音符範圍 A0–C8；不在鍵盤畫面內的音符仍可播放。
- 若聽不到聲音，點一下琴鍵讓瀏覽器啟用聲音。以 Tab 選擇琴鍵，Enter 或 Space 可彈奏。

## GitHub Pages

把網站檔案（含 `index.html`、音色模組及編碼器）放在目標發布根目錄，用倉庫的 **Settings → Pages → Deploy from a branch** 選擇 `main` 分支及 `/ (root)` 目錄，再按 **Save**。若倉庫主分支不叫 `main`，選擇實際分支。不需要組建步驟。尚未發布時也可直接本機試用。
