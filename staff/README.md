# Piano Studio — 獨立 Python 五線譜練習室

## 選歌及版本

頂部「選歌」可揀三個獨立版本，每個都有 Easy／Normal／Hard／Extreme 同自己嘅「KPS 報告」：另開分頁，包含四級曲線及逐小節 CSV／JSON。

| 歌曲版本 | 時間軸 | 四級按鍵數 |
|---|---|---|
| Canon in D · Mutopia D 調總譜 | D 大調，4/4，55 BPM，57 小節，4:08.727 | 471／818／1,386／1,930 |
| Canon in D (Short ver) · 7961 | F 大調，4/4，50 BPM，34 小節，2:43.264（顯示 2:43.2） | 192／258／395／440 |
| Für Elise · 給愛麗絲 | A 小調，3/8，四分音符 72 BPM，105 小節，2:11.250 | 387／634／787／905 |

Für Elise 用公有領域 Mutopia 931 嘅完整 MIDI 形式，保留全部聲部；跟隨所供 MIDI 一次演奏，唔額外加反覆重播。譜首補入一拍靜默去對齊弱起。延音、三連音同裝飾音保持原始演奏時刻。額外音域嘅 PC 鍵位見每粒符頭；無數字鍵盤時可以用畫面琴鍵。

Short 嘅 Easy 192 音按鍵完整保留；其他級別係錄音辨音嘅候選編配，**Extreme 440 音唔等於原作或原錄音嘅完整逐音真值**。依 Easy→Normal→Hard 嘅優先次序固定同一音嘅 gate，確保四級真正包含；伴奏用候選集合嘅其餘音，唔會暗中疊播原錄音。

三個版本嘅 Demo 播譜上鍵加其餘伴奏；跟彈只自動播放伴奏，譜上鍵由你彈。Extreme 冇伴奏。支援同一份譜一次顯示 4／8／12／15 行。

**Windows：解壓完整資料夾，雙擊 `Start-Canon.cmd`。** 需要 Python 3.10 或以上。會用一個可用嘅本機連接埠開自己嘅瀏覽器視窗／分頁；唔需要 Virtual Piano、GitHub Pages、互聯網或額外 Python 套件嚟播放。關閉啟動視窗或按 Ctrl+C 可停止本機服務。指定連接埠亦可用 `python canon_studio.py --port 7436`。

## 點試

1. 首頁預設「Mutopia · D 調總譜 / Extreme」。按 **Demo** 從頭播放全 57 小節；想比較 192 音版本，切去「7961 錄音配譜 / Easy」。綠色直線由左向右行，行過起音就彈琴，翻頁同鍵盤著色都跟同一個 Web Audio 時鐘。可暫停、跳時間、手動翻頁。7961 嘅 F 調 Easy 開頭有 4.8 秒休止；D 調全譜由第一拍開始有低音。
2. 睇兩組五線：高音及低音譜表各五條線。預設 **PC 符頭：開**：每粒音符頭原本嘅位置直接寫上要按嘅實體鍵，和弦會逐粒顯示。按「PC 符頭」可切返傳統音符頭，瀏覽器會記住選擇。琴鍵符號入面，`CL` 係 Caps Lock，`⇥` 係 Tab。可以按實體鍵盤或者畫面琴鍵；下載嘅 MusicXML 維持傳統記譜。
3. 一頁排 **12 行鋼琴雙譜表**：每行有高音五線和低音五線；尾頁只排剩餘音樂。按 **全頁總覽** 可以望晒同一頁，撳其中一行即跳到該段放大讀譜。正常讀譜時會跟行捲動，到頁尾自動翻頁。
4. 試同步可聽第 3 小節（約 **0:08.73**）：上面高音 F♯5 嘅鍵係 `l`（小寫 L），下面低音 D3 係 `w`；兩個音同時出現。前兩小節只有低音，係原譜編排，唔係漏播右手。
5. 想核對機器估嘅音，開「錄音辨音核對」。拖原錄音嘅時間線，對照附近估計嘅音高、起音、時值、按鍵同模型強度，亦可將一粒候選音單獨用鋼琴試聽。Demo 本身只播琴，唔會靠播錄音扮作逐鍵發聲。

「顯示」可揀同一難度嘅 4、8、12 或 15 行雙手譜，同時睇多幾行。每格有行號及小節，按行號順序讀；播放自動轉到下一組。歌名、工具及畫面琴鍵預設收起，按「展開工具及琴鍵」可叫返出嚟，實體按鍵仍可用。點任何一行放大到該段，或者揀「一般讀譜」喺原位繼續。網址參數例如 `?source=reference&level=normal&view=rows12&bar=13`。

按「KPS 報告」可睇[四級 57 小節密度曲線](review.html?report=kps)（[離線 HTML](analysis/density-review/index.html)）。D 調 Normal 同 Hard 已採用報告嘅平滑方案；Easy、Extreme、第 1–6 小節、尾段第 57 小節及所有原有時值不變。試密集段可由[Normal 第 19 小節](index.html?source=reference&level=normal&view=rows12&bar=19)或[Hard 第 19 小節](index.html?source=reference&level=hard&view=rows12&bar=19)以 12 行打開，撳 Demo 即聽。

## 兩個譜源請勿混為一談

| 7961 錄音版本，約 2:43 | 實際可按鍵數 | 相對原有譜面 |
|---|---:|---|
| Easy | 192 | 原有全部起音、放鍵、音高、力度 |
| Normal | 258 | 原譜 + 66 個估測按鍵 |
| Hard | 395 | 原譜 + 203 個估測按鍵 |
| Extreme | 440 | 原譜 + 248 個估測按鍵 |

曲名係 Canon in D，但 **7961 呢個練習編曲實際係 F 大調、4/4、每分鐘 50 拍**。四級都係同一個音軌時間軸，保留全部 Easy 按鍵。較高難度包含較低難度所有起音；新增音嘅時值可以截短，令新增聲部可彈。呢啲係 PoC 試彈編配，唔係搵返官方四級譜。全數可用既有 42 個實體鍵位，唔會暗中移調。

### Mutopia D 大調：同一首歌，由 Verse 到全譜

四級都係完整 57 小節、♩=55、約 4:08.7。**Verse 指練習用主旋律骨架，唔係只播其中一段。** Easy 沿用之前 D 調 Normal 嘅 471 個起音同 PC 鍵位；其中一個重疊同音按全譜較長嘅時值收尾。想聽 192 音嘅舊譜，選另一個「7961 錄音配譜」譜源，唔好混用兩隻調。

| D 調難度 | 你負責嘅部分 | 要按 | 每秒按鍵（平均） | 自動伴奏 |
|---|---|---:|---:|---:|
| Easy · Verse | 簡化第一小提琴旋律，低音隔拍入 | 471 | 1.894 | 1,459 |
| Normal | 保留 Easy 同完整低音，第 7–56 小節每節 12–20 鍵 | 818 | 3.289 | 1,112 |
| Hard | 保留 Normal，補入更多聲部，第 7–56 小節每節 16–37 鍵 | 1,386 | 5.572 | 544 |
| Extreme | 三條小提琴聲部同全條低音線 | 1,930 | 7.760 | 0 |

**Demo** 會同時奏出譜上按鍵及其餘伴奏；**跟彈** 由你彈譜上嘅音，程式只自動播其餘音。伴奏係同一份 D 調總譜逐音抽出，用同一部取樣鋼琴同同一個播放時鐘，唔係疊播背景錄音。已交畀你嘅音唔會再喺伴奏重複；Extreme 跟彈時，唔按就冇聲。按鍵 KPS 唔包括伴奏。

D 調版除原有 42 個實體鍵外，另加 `a` = D2、`g` = F♯2、`[` = C♯6、`]` = D6。L⇧ / R⇧ 區分左右 Shift，唔會將高低音摺返另一個八度。

## 程式點樣做、可以信到幾多？

- `analysis/transcribe.py`：解碼整段錄音，用本機 Basic Pitch 模型輸出 MIDI 音高、起音、時值、模型強度、對應 PC 鍵；唔上傳音檔。`analysis/README.md` 有重跑、安裝分析依賴同測試方法。
- `build_score.py`：從可核對、隨附嘅譜面來源重建譜，不靠錄音估算已知音。輸出 `data.json`。
- `arrange_recording.py`：載入對時嘅 Easy、核對 Canon 音檔指紋，再分級加候選。排除相同音高重疊、不可綁定或明顯偏離拍點嘅候選。用網格、同時按鍵數、每秒密度、手距同每譜表額外聲部限制，唔係調低模型門檻就冒充高難譜。每個新增按鍵都保存候選索引、原始估計起音同強度，可以追查。輸出 `recording.json`。
- `export_notation.py`：匯出兩個譜源、四個難度，共 **8 個 MusicXML**；真正有高低音譜、聲部、休止同跨小節連結線。

實際混音長 163.2 秒，偵測到 562 個候選；只有 40 個同稀疏 Easy 譜吻合（同音高、起音 ±100 ms）。原譜唔係混音內所有聲部嘅標準答案，唔可以把其餘 522 個當作全部正確或全部錯誤。另用已知 192 音渲染一段純鋼琴錄音測試：192/192 真音都偵測到，但有 21 個額外音。**唔可以將呢個純鋼琴結果當成真實混音準確率。**

通用辨音工具可接其他音檔，亦可提供可選參考。若要套用到其他歌嘅四級樂譜，需要每首歌自己經核對嘅節拍、拍號、聲部及對齊鍵譜；本 PoC 唔會將 Canon 嘅固定速度直接套落其他歌曲，Für Elise 使用自己嘅完整譜源，唔套用 Canon 嘅速度或按鍵數。

## 重建／測試

要重建密度報告，由本資料夾依次執行 `python -B analysis/review_density.py`、`python -B analysis/bundle_review.py`。第一步讀取 D 譜面產生曲線；Short 使用 --input recording.json --out analysis/density-recording --no-proposal，Für Elise 使用 --input elise.json --out analysis/density-elise --no-proposal。第二步同步工作室報告入口；兩步都唔會改琴譜。

播放用資料已備妥。喺呢個資料夾執行：

~~~powershell
python -B build_score.py
python -B build_short_layers.py
python -B build_elise.py
python -B export_notation.py
python -B analysis/bundle_library.py
python -B -m unittest discover -v
~~~

重做神經網絡辨音先需要 `analysis/requirements.txt`。授權及出處：`SCORE-SOURCES.md`、`samples/SOURCE.json`、`analysis/model/`、`vendor/LICENSE-vexflow.txt`。本機私人原錄音、辨音模型及原裝商業取樣唔係公開部署內容；唔好將整個測試包公開上載。公開站只載入經核對嘅演奏 JSON、程式及可再分發琴音，並保留來源／候選說明。
